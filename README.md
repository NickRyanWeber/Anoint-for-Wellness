# Anoint for Wellness

A simple, professional one-page website for Anoint for Wellness.

## About This Site

This is a single-page website showcasing:
- Bio and background
- Kindness projects
- dōTERRA products
- Wellness cards
- Organizations supported
- Social media links
- Contact information

## Viewing the Site

The site is deployed via GitHub Pages at: https://nickryanweber.github.io/Anoint-for-Wellness/

## Updating Content

To update the content:

1. Open `index.html` in a text editor
2. Update the text sections as needed:
   - **About section**: Update the bio and credentials
   - **Offerings section**: Modify the descriptions of projects, products, and cards
   - **Organizations section**: Add specific organizations supported
   - **Contact section**: Update email address and social media links
3. Save the file and commit the changes
4. The site will automatically update on GitHub Pages

## Updating Styles

To change colors, fonts, or layout:

1. Open `styles.css` in a text editor
2. Modify the CSS variables in the `:root` section to change colors
3. Adjust fonts by changing the Google Fonts import in `index.html`
4. Save and commit the changes

## Social Media Links

Currently, the social media links are placeholders. Update them in `index.html`:
- Instagram: Line with `https://instagram.com/anointforwellness`
- Facebook: Line with `https://facebook.com/anointforwellness`
- LinkedIn: Line with `https://linkedin.com/in/anointforwellness`

## Email Contact

Update the email address in the contact section from `contact@anointforwellness.com` to the actual email address.

## Technical Details

- Pure HTML and CSS (no build process required)
- Mobile responsive design
- Modern, clean aesthetic
- Optimized for readability and accessibility
